# BioTasks documentation

BioTasks provides prompt inspection, reusable notebook/worker helpers and
operational guidance for preserving research artifacts.

| Document | Purpose |
| --- | --- |
| [Prompt inspection](prompts.md) | Available templates, CLI behavior and Python helpers |
| [Notebook factory building blocks](notebook-helpers.md) | Python conversion, file profiles, GLM transport and explicit limits |
| [Research artifact storage](storage.md) | Public eligibility, snapshot manifests, verification and retention |
| [Contribution guidance](../AGENTS.md) | Setup, checks, permanent research branches and focused promotion |

See [issues](https://github.com/Open-Athena/biotasks/issues) for experiments and
results. Broader research planning lives outside the repository. Each experiment
and established tool should be understandable from its own records and docs.
