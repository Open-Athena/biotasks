## Description: ancombc2 crashes with a hard `ValueError` on a small two-group dataset. The exception is raised by `np.quantile` inside the bias-variance estimation (`_estimate_bias_var`), but the NaNs that cause it are produced earlier, in the EM loop that estimates the sampling bias (`_estimate_bias_em`). Responsibilities there are per-feature weighted Gaussian densities, normalized with: `resp /= np.sum(resp, axis=0, keepdims=True)`. For a feature whose estimated coefficient variance is extremely small, all three weighted densities underflow to zero, so this normalization is 0 / 0 and the responsibilities become NaN (NumPy emits `RuntimeWarning: invalid value encountered in divide` on that line). The NaN responsibilities propagate into the mixture weights, which are later used as quantile probabilities, and `np.quantile` rejects them. Reproduction: `import pandas as pd` / `from skbio.stats.composition import ancombc2`; table = pd.DataFrame([[154, 188, 68], [143, 63, 177], [30, 154, 96], [131, 167, 150]], index=list('abcd'), columns=['f0', 'f1', 'f2']); metadata = pd.DataFrame({'g': pd.Categorical(['a', 'a', 'b', 'b'])}, index=list('abcd')); result = ancombc2(table, metadata, 'g', p_adjust=None).result. Error: RuntimeWarning 'invalid value encountered in divide' at the responsibility normalization, then 'ValueError: Quantiles must be in the range [0, 1]' from np.quantile(beta, (pi1, 1.0 - pi2)) inside _estimate_bias_var. Expected behavior: the call should complete; R ANCOMBC runs the same data without error (it treats the undefined 0/0 responsibilities as zero) and returns, for the g[T.b] contrast, Log(FC) [-1.08292235, 0.16646377, -0.13155807] and p-values [0.25770796, 0.85244671, 0.87755871]; since scikit-bio's ancombc2 is meant to reproduce the R implementation it should return these values instead of crashing. Also note the same underflow can leave a mixture component with zero total responsibility across all features, making that component's mean update another 0 / 0, so the EM iteration should be kept NaN-free end to end, not just at the responsibility normalization.
