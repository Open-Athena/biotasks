# Experiment completion audit

This checklist implements the published protocol; it does not change its scope or define success around the observed results. It is preparation only until final authoritative checks are recorded. Current result progress is recorded in `cohort-summary.json`; this checklist does not assert completion.

| Requirement from the protocol | Authoritative evidence to inspect before closure | Final audit |
| --- | --- | --- |
| Preserve the ten approved repositories, existing scientific-field annotations, source refs and common September window; no substitutions | `protocol.md`, `protocol-provenance.json`, `selection.json`, `cohort.json`, original `599af492` checkpoint, preflight complete-window/newest-300 inventories | Pending |
| Use pinned official source with the agreed settings and only approved infrastructure/accounting adaptations | `pins.json`, all native configs, `input-checkpoint.json` SHA256 values, original submission source, installation records, saved requests and resource wrappers | Pending |

| Respect reserved-resource and execution budgets, count failed infrastructure and all attempts | Actual Iris attempt start/end timestamps and resources; sum allocated CPU-hours against 100; original 150-minute job, 84-minute setup/native and separate one-hour controls configuration; no new workers/accelerators | Pending |

The final live audit and issue/storage lifecycle are separate from `cohort_result_evidence_complete` in the accounting helper. A fixture, a green metadata gate, an intended cleanup, or a terminal wrapper state alone cannot prove this checklist complete. Do not close the issue or mark the goal complete until every row has current supporting evidence.
