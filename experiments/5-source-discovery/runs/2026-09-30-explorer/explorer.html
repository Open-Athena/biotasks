HOW TO READ THIS EXPLORER

Snapshots, not a universal ranking

The four lists each contain 200 canonical sources selected within recorded discovery pools. They are not exhaustive rankings of all biological software. A source may be a GitHub repository, a repository on another host, or an official source archive. Packaging-only distributions map to their upstream source; independently maintained bindings and forks remain separate.

Read the two correlation views differently

The ranking plot conditions on sources selected by both approaches at the chosen cutoff. It re-ranks within that intersection, preserving the stored ordering. The adoption panel instead holds the original 95-source inventory fixed and uses available measurement pairs with average ranks for ties. Neither estimates a population-wide relationship. Raw scores are not comparable across registries, so the explorer never combines them into a composite score.

Labels describe the source’s main role

Source type, primary group and finer topic are frozen assistant annotations from metadata and selected README checks. They have not received independent human validation. A software source can contain tutorials; a resource index is not assumed to contain executable exercises. A single primary label does not capture every use of a source. GitHub topic tags are shown separately in source details and are often missing.

Filtering and interpretation

Depth means rank ≤ the selected cutoff in at least one list. Filters select within that union; original rank numbers are retained. Comparison denominators use the filtered members of each list. Exact membership or shared-pair selections apply only to the source table and are shown above it. Composition percentages use each filtered column as their denominator; the merged column deduplicates sources across lists. The depth curve ignores the depth selector so that all cutoffs can be compared. The 95-source adoption panel ignores all discovery filters.

Evidence and reproducibility

This page embeds its data and runs offline. It makes no provider requests. External links open the referenced sources and records. Counts and plots are derived from saved measurements; no new scientific eligibility decisions, source collection, candidate execution or task validation was performed.
