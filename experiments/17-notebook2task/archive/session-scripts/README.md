# Historical session scripts

These one-off launch, collection, inspection and editing scripts were recovered from session scratch storage at closure. They supplement the maintained experiment scripts; they are not a supported replay interface. Files use `.txt` to prevent accidental launches or repeated edits. Some scripts describe failed or abandoned attempts, not the final implementation. Temporary input paths may no longer exist; final outputs and native evidence are preserved elsewhere in the experiment.

The manifest records original and archived hashes and every private-identifier replacement. Private service/controller names, CPU cluster identifiers, secret-store project names and private Marin checkout paths are placeholders. Credential values and runtime configuration are not included. Historical scripts that read secrets must only be adapted under fresh execution authorization; archiving this experiment does not authorize a rerun. The approved access guidance remains outside the public repository.

Generated browser script extractions are represented by the committed HTML/template rather than duplicated here. Issue drafts are represented by the published body and append-only comments. Downloaded dependencies and node_modules are represented by lockfiles and vendored source. Screenshots are not required to rebuild the published explorer.
