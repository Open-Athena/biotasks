# Preserved failed attempt and correction

The initial cytopathology trial rejected training because it interpreted the
stage-1 execution restriction as a solver-task restriction. Classify this as
harness-induced rejection, not baseline scientific viability. Retry clarifies
that training may be required in the proposed task while not executed during
idea authoring. SETA text remains unchanged; only the output path changes.

The original resource monitor tracked the process group; GNU timeout created a
separate group, so its reported RSS undercounts descendants. Host load/memory
checks still ran. No original child remained afterward. Subsequent trials use
--foreground timeout and a descendant-tree RSS monitor. Do not cite the first
reported peak as full-worker memory usage.
