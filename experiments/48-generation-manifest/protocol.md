# Manifest generation handoff

Research starts from the verified main commit in `source-main.json`, on
`codex/research/48-generation-manifest`. Child48 of epic33 follows the actual
reference45 and experimental recipe47; neither experiment is silently promoted.

The full goal is an unattended, scalable official PR-to-task pipeline with
deterministic controls, evidence/cleanup and bounded spending. A single known
reference with code-bound paths is not the general configuration interface.
Native generation, local export and validation must remain distinct stages;
an export or successful worker is not a positive/clean scientific task.

Inspect existing upstream/native and project orchestration first. Reuse the
original generator/model observer/budget admission and seven-stage validation
lifecycle wherever their contracts apply. Tasksmith's separate author/design
and quality flow is not a drop-in unchanged pr_runtime invocation; do not switch
to it or call its models. The earlier28 supervisor/history batching already
recorded backlog and per-repository costs; reuse that knowledge rather than
inventing another PR identity/counting convention.

Declare native config, frozen returned candidate descriptors, source/dependency
acquisitions, notices/eligibility, backend, fixed run IDs and cost/CPU bounds in a
manifest. Support at least two distinct repository configurations, multiple/zero
candidates and zero exports without repository-specific Python changes. Preserve
official source/settings and grading. An optional experimental emitter must be
explicit and separately source-bound; no per-task or added model repairs.

Test input/source drift, interrupted effects, uncertain submission, zero output,
unknown/overrun billing, cleanup retention and inert completed recovery. Reuse
the original fresh archived reference for source-bound handoff/regression when
possible; do not regenerate it simply to exercise a new command. Distinguish
an imported completed receipt from a fresh run of a changed implementation.

Initial assessment/implementation is source/offline only, with zero additional
model calls, jobs or admission. Complete47's source-bound outcomes, archival,
accounting and cleanup before any later native admission. All later operations
must fit the existing32CPUh/$90 ceiling (strictly below100extra), existing reserved
capacity only; no extra allowance. Do not merge research or auto-merge PRs.
Any supported extraction needs its own fresh pipeline branch, current source
verification, meaningful regression coverage, docs and reviewable validation.
