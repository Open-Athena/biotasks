without changing the source-bound45 runtime or the official generator. The
manifest declares native configs, complete frozen PR descriptors, upstream
source/dependencies, notices/eligibility, backend/SDK, shared budget, archive and
fixed run identities. Fresh and imported-completed generation are explicit.
There is no PR discovery, task repair, experimental APT policy or added model
call. Explicit execution flags retain the original budget/intent/evidence gates.

multiple/empty candidate batches, zero exports, source/config/notice/adapter/plan

and serial stop on incomplete/held cases. These repository descriptors are
synthetic fixtures, not a live cohort or a PR coverage estimate. The combined
suite adds22 unchanged original generation checks:41 passed in7.03s, peak RSS
60,864KiB, exit0. It exercises original model forwarding, named-secret isolation,
unknown billing, scheduler-zero-attempt release, uncertain submission, all seven
interrupted lifecycle boundaries, evidence-before-cleanup and inert completion.
Exact commands/times/resource records are in `local-checks/`.
