# Private validation plan

Scope: task review is complete; the contract below is what the grader must implement and control before release. All thresholds referenced are to be *chosen from the calibration measurements named in section 5*, not invented here. A failed control or an uncalibrated alternative leaves the corresponding claim unvalidated.

## 1. Endpoint A — `cell_clusters_umap.csv`

1. **Cell identity (exact, deterministic)**: recompute the expected cell universe from the public inputs (per-sample barcode lists in file order, s1d1 first; min_genes >= 100 recomputed from the count matrices; step-2 deduplication suffix rule). Check the `cell_id` set, the per-cell `sample` labels and the row count exactly; no duplicates. Controls: dropping 1% of cells, perturbing deduplication suffixes, or swapping the sample order must fail.
2. **Cluster partitions (four columns, each separately)**: build the solver-vs-reference contingency per column, solve the optimal label assignment (Hungarian on cell-set overlap), and report matched accuracy (fraction of cells under the matched labeling), ARI, NMI. Acceptance thresholds from calibration (5). Wrong-method controls, each of which must fail at least one targeted check: leidenalg flavor instead of igraph; unweighted graph; a different resolution's values placed in a column (e.g. `leiden_res_2.00` values in `leiden_res_0.50`); fixed 2 iterations for the step-14 calls (vs run-until-stable); different seed (e.g. 1); different neighbor count (k=10 or k=30); clustering on the raw counts or on the log matrix instead of the connectivity graph; randomly shuffled assignments.
3. **`cell_type_lvl1` (named classes; no name rematching)**: biological lineage names must not be aligned across solutions by best name match (that would silently accept, e.g., monocytes labeled Lymphocytes). Check (i) internal consistency: solver's `cell_type_lvl1` equals the source dictionary applied to the solver's own `leiden_res_0.02` labels; (ii) scientific agreement: per-lineage precision/recall/F1 and overall labeled accuracy against the reference, after the grader has fixed the label correspondence using the resolution-0.02 contingency. Wrong controls: two dictionary entries swapped; the dictionary applied to `leiden_res_0.50`; a different dictionary. Calibration decision required before release: measure whether community numbering (hence the dictionary application) is stable under an independently computed conforming solution; if numbering drifts while communities match, define acceptance through the community-correspondence route (solver lineage must equal the dictionary applied to a labeling that best-matches the reference communities) — never through rematching lineage names between solutions.
4. **UMAP**: checks — exactly two finite components, no constant column; embedding validity against the graph: kNN-trustworthiness and continuity (k=15) with respect to the kNN graph recomputed from the same inputs; Spearman correlation of embedding distances vs connectivity weights over nearest-neighbor pairs contrasted against random pairs (discrimination control must separate these). Reference comparison only after rigid alignment: Procrustes allowing rotation + reflection + translation (whether uniform scaling must also be allowed is a calibration measurement); report post-alignment coordinate correlation and pairwise-distance correlation. Wrong-method controls that must fail: random initialization instead of spectral; min_dist 0.1; a 2-D PCA of the log-normalized matrix in place of UMAP; an embedding built on the un-normalized counts graph. Valid-variation controls that must pass: column swap (umap_2, umap_1), sign flips, reflections.

## 2. Endpoint B — `rank_genes_groups_leiden_res_0.50.csv`

1. **Row identity (exact, deterministic)**: the gene universe recomputed from the public inputs (feature names made unique, inner-joined across samples, filtered to genes detected in >= 3 cells) and the group set equal to the labels present in the solver's `leiden_res_0.50` column (cross-checked against endpoint A); exactly one row per (group, gene); row count = groups x genes. Controls: a missing group block, extra gene rows, or duplicated gene rows must fail.
2. **Ranking validity**: within each group scores are non-increasing; pvals in [0,1]; pvals_adj >= pvals and <= 1; logfoldchanges finite; no blanks.
3. **Independent statistical recomputation (no reference outputs read)**: for a stratified sample of groups and genes (top-ranked, mid-ranked, zero-score), recompute from the public inputs and the solver's own cluster labels: the average-rank (tie-averaging) rank-sum z without tie correction, the two-sided normal p, the within-group Benjamini–Hochberg adjustment, and the expm1-of-mean log2 fold change. Value-level comparison. This is the core wrong-method check and also validates the input provenance end to end. Wrong-method controls that must fail: t-test scores; tie_correct=True; Bonferroni instead of BH; fold changes computed on raw counts; groupby on `leiden` (resolution 1) or `leiden_res_0.02`; only highly-variable genes; a single reference cluster instead of "rest".
4. **Reference agreement after label correspondence**: per matched group, Spearman rank correlation of scores across all genes; top-K gene-set overlap (Jaccard, K = 5, 25, 100); sign agreement; top-5 `names` comparison. Ties: rows with identical scores within a group are order-ambiguous — compare tied rows as a set (group by score value), never by position.

## 3. Endpoint C — `rank_genes_groups_params.json`

Exact equality of the six key–value pairs. Wrong controls: groupby "leiden", method "t-test", corr_method "bonferroni", use_raw true, layer "counts".

## 4. Required executable controls (planned, not yet run)

1. **Reference self-test**: re-run the reference pipeline and the full grader; every check passes.
2. **Empty/no-op tests**: empty files, header-only files, all-constant tables must fail.
3. **Missing-endpoint tests**: remove each of the three outputs in turn; the corresponding checks must fail.
4. **Wrong-method controls**: every control listed in sections 1–3 must fail at least one targeted check; record the measured separation between each control and the reference — this separation is what justifies the acceptance thresholds.
5. **Valid-variation / representation tests that must pass**: (a) a label-permuted copy of the reference outputs, with the DE `group` column relabeled consistently and `cell_type_lvl1` reproduced by re-applying the source dictionary to the permuted `leiden_res_0.02` labels (permutation of *cluster labels* is a valid variation; renaming *lineage classes* is not); (b) the DE table with group blocks reordered; (c) reformatted reference files (parquet or a different CSV dialect) to confirm the value comparison is representation-only; (d) UMAP column swap / sign flip / reflection after alignment.
6. **Independent conforming alternative (calibration)**: implement the pipeline independently from the public inputs without access to reference outputs (suggested: exact 15-NN in place of the approximate index, independent UMAP/Leiden/Wilcoxon code, or a differently-versioned stack) and measure its values on every metric in sections 1–3. Use the measured band between this solution and the reference to set numeric tolerances; document that if any control fails to separate or the alternative does not fit a proposed tolerance, the corresponding check is returned to unvalidated.
7. **Repeatability**: repeat the reference run once in the pinned environment and record run-to-run agreement (bitwise or drift size) to decide whether the tolerance needs headroom for the pinned stack's own variation.

## 5. Calibration agenda (measurements that fix thresholds)

Named metrics needing thresholds, each justified by the measurements in sections 4.4, 4.6 and 4.7: matched accuracy / ARI / NMI per clustering column; per-lineage F1 and labeled accuracy; UMAP trustworthiness/continuity and post-alignment correlations (including the scaling-freedom decision); Spearman of DE scores, top-K overlaps, value-level deviations for scores/p/logfoldchanges; tie-band width. No numeric tolerance may be published before these measurements exist.

## 6. Instructed internal procedures the terminal outputs cannot distinguish

QC metric computation (step 4), Scrublet doublet scoring (step 6), the retained counts copy (step 7), plot rendering including the implementation-internal heuristic dendrogram for the resolution-0.50 dotplot (step 16), HVG dispersion/mean annotation columns beyond the selected flag, PCA variance ratios, and the neighbor distance matrix. Do not add intermediate exports for these and do not claim they are verified; the reward is defined only over the checks above.

## 7. Reward and provisional items

- One binary reward: every justified scientific check across endpoints A, B and C must pass; any single failure fails the run.
- `solver_timeout_seconds` is provisional per task policy; re-confirm after the calibration run (section 4.6) provides a second runtime data point — the reference completed with a large margin.
- Software portability (alternative stacks) is claimed only to the extent validated by section 4.6; exact bitwise agreement in a repeated reference run alone does not establish that other conforming implementations must match.
