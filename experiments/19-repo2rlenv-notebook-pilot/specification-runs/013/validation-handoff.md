Unresolved endpoint-comparison questions and dependencies for the executable validation stage (no checks, thresholds or presumed answers are claimed here):

1. **Reference repeatability (unmeasured).** Only one pinned run is recorded. Determine whether repeated executions of the same pinned stack reproduce identical cluster labels, UMAP coordinates and DE values (igraph/leiden RNG streams, umap-learn/numba JIT, BLAS threading are candidate variance sources), and what run-to-run stability — if any — a tolerance regime should assume.
2. **Cluster-label conventions.** `leiden`, the `leiden_res_*` columns, the DE `group` values and the `cell_type_lvl1` map are all keyed to specific label values. Decide whether grading requires literal label equality or a cluster-correspondence rule, and how any correspondence must propagate to the annotation column and DE `group` values. Relabeling is a representation change that can alter which cells carry which lineage label — not automatically harmless.
3. **Map coverage.** `cell_type_lvl1` covers only `leiden_res_0.02` labels "0"–"4"; the reference run populated the column fully. Decide the expected treatment if a compliant output's coarsest clustering produces labels outside the map.
4. **UMAP comparison basis.** Decide coordinate-level numeric tolerance versus orientation/scale-invariant embedding comparison. Embedding sign and rotation are not canonical across implementations; any invariant comparison would itself need validation before being accepted.
5. **DE value handling.** Decide treatment of exact-zero `pvals`/`pvals_adj` (underflow), tolerances for `scores` and `logfoldchanges`, whether tied scores may reorder rows within a group, and whether the stored group order must be reproduced.
6. **Row alignment.** `cell_id` values embed anndata's `obs_names_make_unique` suffixing. Decide whether alignment is by `cell_id` string identity or positional, and whether alternative identifier conventions are acceptable.
7. **Cross-file dependencies.** File B's `group` set must equal file A's `leiden_res_0.50` label set (set identity only — per-group cell counts live in A, per-group gene rows in B; not interchangeable cardinalities); file C must describe file B's test. Decide whether these become alignment checks.
8. **Alternative implementations.** Decide which internal choices are visible only through endpoints (e.g., HVG membership cascades into every result although HVGs are not exported) and what evidence, if any, will be accepted in place of the scanpy 1.12.4 stack. No equivalences are promised here.
9. **Verifier sizing and constraints.** File B is a large leaderboard CSV (tens of MB); decide parsing/comparison method (numeric parse vs byte comparison) and check it against the 120 s verifier budget. Confirm the provisional 600 s solver timeout (reference run: 147.5 s, ~4.9 GiB peak child RSS — observations, not solver bounds).
