Gene sets for QC: genes whose symbol starts with 'MT-' (mitochondrial), starts with 'RPS' or 'RPL' (ribosomal), or contains a match of the regex ^HB[^(P)] (hemoglobin).4. PCA: 50 principal components of the log-normalized matrix restricted to those 2,000 genes, mean-centered but not variance-scaled per gene.10. Neighborhood graph: k-nearest-neighbor graph of cells in the 50-dimensional PCA space, 15 neighbors per cell, Euclidean, seeded (random_state 0).11. UMAP: 2-dimensional embedding of that graph with reference defaults (spectral initialization, min_dist 0.5, spread 1.0, random_state 0).12. Lineage annotation: cell_type_lvl1 = map leiden_res_0.02 labels through the analysis's fixed source dictionary: 0 -> Lymphocytes, 1 -> Monocytes, 2 -> B Cells, 3 -> Erythroid, 4 -> Erythroid.14. Differential expression: for each cluster of leiden_res_0.50 versus all remaining cells (one-vs-rest, reference='rest'): per gene, a two-sided Wilcoxon rank-sum test on the full filtered log-normalized matrix (all retained genes, not just HVGs), using average ranks for ties, normal approximation, no tie correction; Benjamini-Hochberg adjustment over genes within each group; and a per-gene log2 fold change of mean expression between cluster and rest computed by back-transforming the group means of the log-normalized data to natural scale (expm1) with a +1e-9 zero-guard added to numerator and denominator.
