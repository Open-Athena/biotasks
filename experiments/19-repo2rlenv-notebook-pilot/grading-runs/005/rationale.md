**Calibration re-measured in this session (evidence, not prose).** All numbers below were computed here by key-aligned comparison of the three executed artifacts available locally (reference, recomputed oracle, independent alternative; 398,259 rows each; note that the alternative's rows are stored in a different order, so alignment by (cluster, gene) — not row position — was used, and an early naive positional comparison produced a spurious 25.22 max |Δlog2fc| that the key-aligned comparison refutes at 1.935e-6). **Unresolved limitations (unchanged, no blocker).** (1) The score tolerance is calibrated to the float32-vs-float64 tie residual on this dataset; a submission with a genuine error below 2e-4 in z would pass undetected — quantities at that scale are not resolvable by the available evidence. (2) Software portability is not claimed beyond the demonstrated agreement of two independently executed implementations plus the reference self-comparison; byte-identical reruns of the recorded run were used only to check repeatability, never as an acceptance basis. (3) The grader never reads the task inputs; population/gene-universe reproduction is enforced through key coverage against the reference cross product rather than by re-deriving the filters — a submission using a different but coincidentally identical gene universe is indistinguishable by design, which keeps the grader fast and avoids duplicating the scientific method.
