# Bounded network probes

A timed-out probe must not be parsed as a successful JSON result. The original162failure is preserved with complete archives and cleanup; its precise stalled call was not captured. Socket connection timeout does not bound hostname resolution.

The same representative public target set is retained. Each connector now runs in a bounded child process, including resolution; a stalled child is killed/reaped. Expected connection failure uses a distinct exit code, while unexpected child failures do not count as isolation evidence. Host controls use the same probe and require positive reachability before a sandbox preflight. Remote network control still requires provider readback and the complete expected probe result within the existing45secondcontrol/30secondcommand allowances; incomplete/non-text/malformed results remain uncertain and block further commands.
