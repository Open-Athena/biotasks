## Scientific meaning / identity constraints

- Per-frame tables: one row per trajectory frame, ordered by frame index; **row order carries the frame correspondence** — comparison must be order-aware (identity = (table, frame)). Cross-file: identical Frame/Time columns expected in tables 2–5 for the same trajectory.
- `Frame` = 0-based reader frame index; `Time (ps)` = reader-reported frame time in picoseconds. **Label-defect note:** reference CSVs carry header `Time (ns)`, but the producing operation reports ps: DCDReader `units = {'time': 'AKMA', 'length': 'Angstrom'}` (MDAnalysis 2.9.0 `DCD.py:122`), delta converted AKMA→ps at init (`DCD.py:147`), `ts.time = (frame + istart/nsavc)*dt` (`DCD.py:228`). First-frame time is ≈1 ps (reader-folded istart offset), not 0. Public schema uses `Time (ps)`; comparator must align reference column by position, not by exact header string. Do not silently relabel in the reference artifacts; keep original evidence.
- RMSD units: ångström (DCD coordinates Å, `convert_units=True` default).
- Methodology (verified in pinned MDAnalysis 2.9.0 `analysis/rms.py`):
  - `ref_frame=0` for all trajectory analyses (explicit at lines 107/149; signature default at rms.py:385 for the two weighted runs).
  - Superposition minimizes the (weighted) RMSD for the `select` group; group-selection RMSDs computed with no further fitting (rms.py:761-790).
  - **Mass weights propagate to group selections**: default `weights_groupselections=False` (rms.py:383) with `weights='mass'` → `_prepare` sets groupselections weights to `'mass'` (rms.py:670-686: `not iterable(self.weights)`; strings non-iterable per `lib/util.py:1102-1106`), then `.masses` substituted (rms.py:685-686). Notebook prose claims CORE/LID/NMP "remain unweighted" in the mass table — **prose/code discrepancy**; the executed values (and hence the required answer) are mass-weighted for all groups in output 4. Public brief states this explicitly.
  - Weight mean-normalization (rms.py:687-700) cancels in the RMSD ratio: only relative weights matter.
  - Resid weights: per-atom `resids` of `protein and name CA` (select/'C-alphas') and of each domain's `backbone` selection (CORE/LID/NMP).
  - Output 3: allocation `rms.RMSD(ca, ca, select=CORE, ref_frame=0)` with `ca = u.select_atoms('name CA')` — mobile and reference are both the CORE∩CA atoms; superposition group identical to the measured group.
