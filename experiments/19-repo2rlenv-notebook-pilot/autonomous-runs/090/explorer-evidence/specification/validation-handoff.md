## Comparison rules (proposed, not yet validated)

- **Schema/coverage**: per file, the exact column-name set as in the public brief; exactly one data row; identify columns by name (column order free; no need for a row-permutation probe given one row). Empty cells must match the reference's empty cells exactly (`HRV_ULF`, `HRV_SDANN2`, `HRV_SDNNI2`, `HRV_SDANN5`, `HRV_SDNNI5`) — a solver filling these with 0 (or vice versa emptying a defined cell) must fail.
- **Numeric**: compare each defined cell. Propose *relative* error as the primary metric with an absolute floor for near-zero magnitudes (e.g., `HRV_MFDFA_alpha2_Fluctuation` ≈ 1.4e-4, `HRV_MFDFA_alpha1_Fluctuation` ≈ 2.2e-3, `HRV_pNN50` etc.). **No tolerance values are set yet.** Calibration plan: (a) rerun the pinned reference with principled method deviations to measure the scale of legitimate-answer differences — `psd_method="burg"`, `interpolation_rate=4` (Kubios), `normalize=False`, `correct_artifacts=True`, peaks on `ecg_clean`-ed ECG, detrended RR series, pNN with the standard denominator `len(diff_rri)`; (b) if available, one independent reimplementation of a few headline indices (RMSSD, LF/HF, SampEn, DFA_alpha1) to estimate cross-stack numerical noise; (c) choose tolerance bands strictly between observed cross-noise and observed method-deviation magnitudes; do not use a round safety factor without these measurements. Expectation to verify: method deviations change headline values at the percent-to-tens-of-percent level, far above cross-stack noise — if the two distributions overlap for any index, that index's tolerance must stay unresolved rather than be widened to hide the difference.
- **Cross-output dependency**: for every column shared between `hrv_indices.csv` and the per-domain tables, values must be identical (same well-defined computation); a mismatch fails.
- **Incorrect-output probes for the executable grader**: cleaned-ECG or artifact-corrected peak detection (different population); Lomb/Burg PSD or unnormalized PSD (different quantity); 2- or 5-minute SDANN/SDNNI filled with numbers; ULF filled with 0; pNN50 computed with the conventional denominator; trapezoid over right-open band edges; frequency columns in the combined table differing from the per-domain table.
