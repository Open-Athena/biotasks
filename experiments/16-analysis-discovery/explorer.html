Expansion to 100 candidate documents

The expansion adds plant phenotyping, neuroscience, immune repertoires, molecular dynamics and more metabolomics. New routes include Hugging Face examples, challenge project repositories, embedded notebooks and tool documentation. Every addition remains separate from the original comparison.

Documents are not independent studies. The marimo pipeline reuses PBMC3k; several structural tutorials reuse AdK trajectories; Kaggle and GitHub HMS notebooks share a challenge. Study clusters are visible in each source’s details.

Frozen 30-document comparison

The main comparison contains 30 selected documents: 10 GitHub, 10 Bioconductor, and 10 from the amended competition-first Kaggle route. This is a purposive sample, not a platform ranking.

The search procedure matters. Generic Kaggle search produced two unresolved document leads. Starting from biology competitions recovered ten inspectable notebook sources, of which seven passed static screening. These are separate cohorts, not a controlled before/after experiment.

What still needs work

Resolve remaining inputs and access. Some Geneformer and DREAM examples depend on untraced processed inputs or model assets. A few catalog documents still need substantive inspection.

Check independent study breadth. Multiple tutorials from one package can teach different workflows while reusing the same experiment. The sample is purposive, so counts do not rank platforms.

Discovery is not exhausted. Systematic paper-to-code searches, citation following, other challenge platforms, and multilingual or non-Python/R resources remain untested. No candidate has entered execution, task authoring or independent validation.

How to read these results

Unit
One analysis document. Confirmed mirrors are aliases; sharing a dataset does not make two documents duplicates.
Screening
Apparently suitable: a biological question, meaningful analytical choices, specific input paths and identifiable dependencies. Excluded: fails these criteria. Unresolved: insufficient accessible evidence.
Data
Input locations were inspected, not downloaded and executed. Observed, adapted, predicted and toy/simulated inputs remain explicitly labeled in source details.
Selection
GitHub: four web queries, then purposive document selection with at most two per repository. Bioconductor: first ten alphabetical workflow packages. Kaggle: four named challenge clusters, up to three notebooks per challenge. Extensions are separate.
Taxonomy
Eight initial subdomains; RNA biology and cellular phenotyping added in the first extension. The new expansion adds plant biology, neuroscience and immunology. Original 8/10-label comparisons remain unchanged. Workflow labels are descriptive annotations, not an independently validated ontology.
Source terms
Code, documentation, biological data and pretrained assets can have different terms. Index inclusion and static suitability do not establish reuse permission.
Effort
GitHub source retrieval: 8.41 seconds; Kaggle: 6.17 seconds. These exclude discovery and manual review. Per-candidate review time and provider costs were not tracked. No paid compute or external model calls were launched.
Reproduction
Manifest, search metadata, hashes and a standard-library builder live alongside this HTML on the research branch. Counts reproduce offline; remote discovery and rendered pages may change. Source bytes are not archived here.

Most source assessments are assistant judgments. Popularity signals are recorded where available but are not comparable across platforms. No corpus-wide recall, scientific score, or release-readiness claim follows from this pilot.
