# Iterative classification pilot: completed bounded pass

The working vocabulary was refined against **35 source documents across 31 hosting repositories**, expanding from 10 to 14, 27, 31 and finally 35 documents. All **18 candidate scientific fields** now have substantive source examples. The vocabulary contains 26 data modalities and 27 operations; unexercised terms remain explicitly marked. These are overlapping navigation categories, not an independently validated ontology or a representative coverage estimate.

## Findings

- Retain three independent facets: **scientific field, data modality, analytical operation**. Store biological setting, design and input origin separately. Each operation needs its target and its role: implemented, exercise, discussed only or supplied upstream. Implemented means source code is present, not successfully executed.
- Keep **repository declared scope and document content independent**. DeepForest declares ecological computer vision, while its inspected nest detector supports image-analysis work without an ecological inference. Broad teaching repositories likewise do not transfer every field to every notebook.
- Separate **model construction, forward simulation, inverse modeling, statistical modeling and spatial statistics**. Editing reaction kinetics is not running a simulation; OpenSim inverse dynamics is not generic normalization; spatial neighborhood statistics are not gene-set enrichment.
- Allow **no scientific field** for generic sequence-alignment methods and software class-development guides. Generic segmentation does not establish a cellular-process question; immune-cell input alone does not establish immunology.
- Track **document role**. A migrated csaw navigation stub contains no analytical implementation; following its declared destination recovered a substantive ChIP analysis chapter. Preserve both identities but exclude the stub from substantive field coverage. The sample contains 31 analysis/teaching documents, one infrastructure demonstration, one generic-method demonstration, one navigation stub and one developer guide.
- Keep source provenance explicit: synthetic RNA examples remain simulated, precomputed results remain upstream, and a proposed or narrated method does not count as implementation. The original 14 documents were revisited under these rules; [the change record](iteration-diff.json) preserves changes relative to v0.2.

## Evidence and accounting

[Readable vocabulary](vocabulary.md), [definitions](vocabulary.json), [decision rules](decisions.md), [document annotations](annotations.json) and [repository annotations](repository-annotations.json) preserve explicit judgments and evidence. [Validation](validation.json) checks pinned identities, locators, term membership, distinct counts and targeted false-coverage cases. It does not establish biological correctness.

All 31 hosting repositories received bounded root-README checks: 29 READMEs were acquired, two unavailable. Seventeen support selected field assignments, ten remain insufficient, two are generic infrastructure/method scope where a specific field is not applicable, and two retain access-unavailable status. These are README-only judgments, not exhaustive repository audits.

One additional attempted document, the scvi CytoVI notebook (N09), exceeded the 8 MiB acquisition cap and is excluded from the 35 annotations. A separately pinned CyTOF workflow supplies a mass-cytometry contrast. [Acquisition records](round3-acquisition.json) preserve the failure; no missing content was guessed.

The [registry reconciliation](registry-reconciliation.json) finds **20 exact pinned-source matches and 15 candidates outside the frozen registry**. No corpus-wide labels were applied. The 4,277-document inventory and its source counts remain unchanged; this sample is not a classified fraction of that inventory. Count distinct document identities, report facet/status denominators and overlaps, and never add overlapping category counts into a total.

## Completion and remaining uncertainty

This bounded pass stops after exercising every retained field, testing generic and misleading cases, reviewing the earlier assignments, independently inspecting repository evidence, and passing identity and accounting checks. Later contrast examples fit the revised schema; they were not a blinded holdout. Classification is assistant static inspection with **no independent biological reviewer, notebook execution or task-quality validation**. Selected operations and repository fields are not exhaustive.

Future expansion should repeat the same cycle: select sources from gaps or disagreements, inspect actual documents, revise definitions with evidence, revisit affected annotations, and version the changes. Freeze the vocabulary only for a particular annotation batch, not permanently. Independent adjudication remains necessary before treating these labels as benchmark ground truth. This milestone completes vocabulary refinement requested before full-corpus annotation.
