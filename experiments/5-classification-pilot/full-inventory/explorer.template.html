BIOTASKS / STATIC SOURCE CLASSIFICATION

Notebook inventory and biological scope

Scientific field, data modality and analytical operation describe different aspects of a source. Repository scope is inspected separately. All notebook and literate formats are included.

Orange labels are provisional rule assignments from source text. Green labels have individual assistant source review. Neither status establishes execution or independent biological validation. Missing labels mean insufficient evidence, not proven absence.

How the inventory is distributed

Charts use the full inventory, independently of table filters. Categories overlap: each document is counted once within a category, and may occur in several categories. Percentages use all 4,245 authoring documents, including sources without labels.

Counts are distinct source locators, not independent biological analyses. Shared collections may be attributed to multiple repositories. Proven extension collisions are excluded; unresolved historical locators remain explicit. Evidence locators use zero-based notebook cells and one-based text lines.
