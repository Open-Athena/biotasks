# xcms input preparation

The pinned xcms repository contains small preprocessed xmse.RData and xdata.RData objects. Both are staged, together with loadXcmsData.R, DESCRIPTION and LICENSE, with hashes in xcms-inputs.json. The official loadXcmsData documentation describes xmse and xdata as alternate representations of preprocessing results from the same faahKO data and settings as the vignette. This is an input-preparation lead, not proof that extraction or exact agreement with the pinned vignette has succeeded: https://sneumann.github.io/xcms/reference/loadXcmsData.html .

The seed selects eight CDF files by indices 1,2,5,6,7,8,11,12 and assigns four KO and four WT samples.
